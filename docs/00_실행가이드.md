# 클로드 코드로 이 프로젝트 이어가기 — 실행 가이드

## 클로드 코드가 뭔가
터미널(맥/윈도우/리눅스)에서 도는 코딩 에이전트. 리포 폴더 안에서 파일을 읽고·쓰고,
테스트를 돌리고, 커밋까지 한다. 이 킷은 그 에이전트가 바로 이어서 개발하도록 준비한 자료다.

## 준비 (5분)
1. 이 폴더(`handoff-kit`)를 새 리포의 루트로 둔다. (예: `schedule-manager/`)
2. 터미널에서 그 폴더로 이동해 `claude` 실행. (설치·로그인은 Claude Code 문서 참고)
3. 처음 한 번 `/init` 를 실행하면 리포를 스캔해 CLAUDE.md를 보강해준다.
   (이미 넣어둔 CLAUDE.md가 있으니 유지/병합)

## 진행 방식
- `PROMPTS.md`의 프롬프트를 **순서대로(P0→P4)** 붙여넣는다.
- 큰 단계는 먼저 **플랜 모드**로 계획을 받고 확인한 뒤 실행시킨다.
- 각 단계가 끝나면 커밋하게 하고, **골든 테스트가 통과하는지** 항상 확인한다.
- 설계 변경이 필요하면 코드부터 고치지 말고 `01_마이그레이션_설계서.md`를 먼저 갱신하라고 지시한다.

## 왜 이렇게 하면 잘 되나
- 설계서·엔진·골든값을 **리포 안에** 넣어 두었기 때문에, 에이전트가 매번 정본을 참조한다.
- 계산 규칙은 참조 엔진과 골든 테스트로 고정 → 리팩터링해도 결과가 어긋나지 않는다.
- 단계가 작고 독립적 → 각 단계가 동작하는 상태로 커밋되어 되돌리기 쉽다.

## 폴더 구성
- `00_실행가이드.md` (이 파일)
- `01_마이그레이션_설계서.md` — 아키텍처 정본
- `CLAUDE.md` — 에이전트 프로젝트 메모리(자동 참조)
- `PROMPTS.md` — 복붙용 단계별 지시문
- `reference/` — scheduler.reference.mjs, wbs_model.json, wbs_calc.py, current_app.html
